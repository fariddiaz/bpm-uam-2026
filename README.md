# Buenas Prácticas de Manufactura (Res. 2674 de 2013)

Exposición de Gerencia de la Calidad, Universidad Autónoma de Manizales, 2026-3.
Presentan Omar Farid Lascarro Díaz y Luis Fernando Beltrán.

- `index.html`: la presentación. Flechas para avanzar, `N` para ver las notas.
- `quiz.html`: BPM Arena, el quiz que se juega desde el celular con el PIN 2674.
- `server.js`: el servidor del quiz. Se ejecuta con `node server.js` y no necesita dependencias.
- Variable `HOST_KEY`: es opcional. Si se define, solo quien tenga la clave puede manejar el quiz.
